1. BOXCRAFT

1) 내용 수정

- 각각의 박스에 예상 디자인을 미리 적용해 볼 수 있도록 하여, 고객이 완성된 모습을 바로 확인할 수 있게 한다.
【답변｜파랑｜상태: 구현됨 ✅】
스튜디오 이미지 레이어 + 예시 디자인 원클릭（Studio「예시 디자인 원클릭」）이 있습니다. 2D/3D에 바로 반영됩니다.
- 각각의 박스에 사용될 종이 재질을 선택하고 적용할 수 있게 한다.

예: 크라프트지는 갈색의 자연스러운 느낌, 아트지는 인쇄가 선명한 매끈한 느낌으로 미리보기에 반영

【답변｜파랑｜상태: 구현됨 ✅】
한국 지종 카탈로그（크라프트·아트지·E/B골 등）+ Studio 선택 UI + 3D 질감 구분（white 코팅감 / blue 냉색）. 엔진은 계속 kraft/white/blue 매핑. 상용 텍스처 팩은 이후 교체 가능（docs/paper_kr_catalog.md）.
- 종이 두께(150g, 250g, 350g, 1골지 등)를 선택할 수 있게 한다.
【답변｜파랑｜상태: 구현됨 ✅】
Studio에서 지종 선택 시 gsm/골에 맞는 thicknessMm 적용, 두께·내면/외면·골방향 UI 노출.
① 먼저 한국에서 주로 사용하는 종이 재질과 두께를 조사·분석한다.
【답변｜파랑｜상태: 완료 ✅】
1차 표 반영: src/catalog/paperCatalog.js + docs/paper_kr_catalog.md.
② 분석 결과를 바탕으로, 종이 두께에 따라 달라지는 박스의 안쪽 크기와 바깥쪽 크기를 PACDORA처럼 함께 표시해 주는 기능을 추가한다.

예: 안쪽 크기를 100mm로 설계해도 종이가 두꺼우면 바깥쪽 크기는 더 커지므로, 두 크기를 함께 보여준다.

【답변｜파랑｜상태: 구현됨 ✅】
Studio 기하 패널에서 deriveSizes 기반 안쪽·바깥쪽 L×W×H 병기.

2) 번역 문제

- 중국어로 제작된 사이트를 자동번역기로 번역하면 한국 검색엔진에서 검색되지 않는 문제가 있다.

예: 추후 각 나라별 언어로 콘텐츠를 별도로 제작하고, 접속 국가에 따라 해당 언어가 자동으로 보이도록 변경해야 한다.

【답변｜파랑｜상태: 구현됨 ✅】
네이티브 zh-CN/ko-KR + 라우트 메타/sitemap/robots/hreflang + 접속국 헤더(CF-IPCountry)·Accept-Language·cookie 기반 자동 언어. 국가별 완전 분리 사이트는 하지 않음.

3) 블로그 기능 추가

- 박스의 종류와 박스별 활용 정보를 소개하는 블로그 기능을 올릴 수 있도록 한다.

예: 화장품 박스, 선물 박스, 배송 박스의 특징과 추천 종이 재질 소개

【답변｜파랑｜상태: 구현됨 ✅】
Django 서버 HTML 직출 /blog/ + Console CMS(중/한). 시드 3편(화장품·선물·운송). SPA가 아닌 서버 렌더로 검색엔진이 본문을 읽을 수 있음.
- 사용자가 직접 만든 박스를 공유하고 자랑할 수 있는 기능을 추가하여 커뮤니티 활성화를 유도한다.
【답변｜파랑｜상태: 미구현】
커뮤니티 공유는 미구현입니다. 블로그 공개 연동과 함께 설계하는 편이 안전합니다(저작권·노출 권한 필요).

4) 곧 추가할 기능 (가능 여부를 확인한 후에 적용)

- 제품별로 박스에 반드시 표시해야 하는 표기사항을 추가한다.

예: KC 인증 마크 및 인증 번호 등

【답변｜파랑｜가능(확인 후)】
KC 마크·인증번호 등 ‘필수 표기 레이어/스탬프’로 넣을 수 있습니다. 표기 문구·위치 규정 리스트가 필요합니다.
- 박스 도면 위에 디자인을 올리면 3D로 렌더링해 보여주는 기능을 제공한다.

→ PDF나 .ai 업로드 시 자동 3D·전개도까지 확장

【답변｜파랑｜조사】
Pacdora: “PDF/.ai 올리면 자동으로 3D+전개도 생성”은 공개 기능으로 보이지 않습니다. 있는 것은 ①템플릿 고르고 그림(로고 등) 올려 3D 보기 ②SVG/DXF 칼선 도면을 올려 접어 3D로 보기 ③작업 후 PDF/AI로 내보내기입니다.

Packative: 박스 고르고 디자인·AI 시안 후 3D 미리보기가 중심입니다. CAD 쪽은 DXF 칼선 가져오기를 말하고, PDF/.ai를 넣으면 자동으로 전개도+3D를 만들어 준다는 식의 공개 기능은 확인되지 않았습니다.

BOXCRAFT: “도면 위에 디자인 → 3D”는 이미 있습니다. PDF/.ai 자동 생성은 양사도 표준이 아니어서, 당분간은 이미지 업로드+기존 3D를 유지하고, 필요하면 나중에 SVG/DXF 칼선 업로드부터 검토하는 편이 맞습니다.

안정성: PDF/.ai를 임의로 넣어 자동 3D·전개도를 만들면 모델이 어긋날 수 있습니다. 파일에 인쇄 그림·글자·가이드가 섞여 있고, 칼선/접선·어느 면이 뚜껑인지 표준 표기가 없어 매번 안정적으로 인식하기 어렵습니다. 데모·반자동(사람이 선 종류를 지정)은 가능해도, 전자동·양산 수준 안정은 기대하기 어렵습니다. 그래서 템플릿(또는 깨끗한 SVG/DXF 칼선) 경로가 더 안전합니다.

5) 가장 어려운 기능 추가

- 박스를 제작하면, 수량에 따른 예상 가격을 표시해 주는 기능이 필요하다.

예: 100개 vs 1,000개 단가 비교

【답변｜파랑｜일정 조정】
동의합니다. 지금은 구독제로 먼저 테스트하고 유입·사용량을 봅니다. 수량별 자동 단가·장바구니·견적은 미뤄 두고, 사이트가 커진 뒤 한국 공급사와 함께 실제 종이박스 판매로 확장할 때 다시 잡겠습니다.

6) 아웃박스 연결 기능

- 포장박스가 만들어지면, 이를 담을 아웃박스(배송용 외부 박스)를 만드는 창으로 이어지도록 유도하는 기능이 있으면 좋다.

예: “이 박스 10개가 들어가는 아웃박스를 만들어 보시겠습니까?”

【답변｜파랑｜상태: 구현됨 ✅】
Studio Outbox + 유도 카피 + 적재 매핑/충전율/한도초과 피드백（제0기 UX 보강）.

7) AI 적용

- AI를 적용할 수 있는지 확인한다. AI를 적용할수록 다른 박스 제작 업체들과 차별화된다.
【답변｜파랑｜상태: 구현됨(키 연결) ✅】
Studio AI 패널（이미지 생성）+ Console/env 키 연결 경로 문서화（docs/paper_kr_catalog.md）. 키가 없으면 가짜 성공 없이 불가 표시.
- 설계 중 문제가 될 수 있는 내용을 미리 알려주어, 초보자도 설계에 문제가 없도록 돕는 알림 기능이 필요하다.

예: 아트지 250g + 고중량/고높이 → 찌그러짐 경고

【답변｜파랑｜상태: 구현됨 ✅】
규칙표 paperRiskRules.js — 얇은 지종+높은 H 등 조합 시 Studio에 노랑/빨강 안내.

8) 추후 공급망 추가 예정

- 이 웹사이트를 통해 한국의 파트너(인쇄소)와 연동하여, 실제 발주를 받을 수 있도록 유도한다.

참고: 한국에서는 이미 대형 인쇄소가 시장을 선점하고 있다.

【답변｜파랑｜상태: 미구현(추후)】
지금은 구독제만 먼저. 사이트가 커지면 한국 공급사와 연동해 실물 박스 판매·발주로 확장합니다. 그때 장바구니·견적·발주 상태를 본격 붙입니다.
- 인쇄소와 협의하여 아웃박스까지 함께 제공받거나, 포장재를 일괄 구매할 수 있도록 유도한다.
【답변｜파랑｜추후】
2단계(실물 판매) 범위. 아웃박스 설계 데이터는 이미 있어, 공급사 SKU/견적만 붙이면 일괄 제공 유도 가능. 장바구니·견적은 그때 고도화.

2. 앞으로의 계획

1) MASSCONNECTED 연계

- MASSCONNECTED에서 제품의 크기가 정해지면, 포장 방법과 박스 포장에도 이 엔진을 사용할 예정이다.
【답변｜파랑｜상태: 미연동】
코드베이스에 MASSCONNECTED 연동 없음. 제품 L/W/H API로 박스 엔진 호출하는 계약만 정하면 연결 가능.

2) 판매 계획

【답변｜파랑｜전략】
1단계(지금): 구독제로 물 테스트 — 가입·무료 횟수·유료/연간으로 도구 사용권을 팔고 트래픽을 봅니다.
2단계(성장 후): 한국 공급사와 협력해 실제 종이박스 판매·제작 서비스로 확장.
후순위: 장바구니·견적(수량 단가 포함)은 2단계에 맞춰 진행하고, 지금은 구독·핵심 설계 기능에 집중합니다.
- 가입하면 10번은 무료로 다운로드할 수 있다.
【답변｜파랑｜상태: 부분 구현 ✅】
조직별 무료 10회 + Studio/Lab 서버 차감 + 업그레이드 의사 등록 + Console 수동 연간 개통. 실제 한국 PG 결제는 미구현.
→ 그 이후에는 5,000원(25RMB) + 부가세 500원을 지급해야 사용할 수 있다.
【답변｜파랑】
단가 모델(회당 5,000원+VAT / 연간 3,000원+VAT) 반영 가능. 결제·세금계산 정책 확정 후 적용.
- 1년 구독을 하면 3,000원(15RMB) + 부가세 300원으로 이용할 수 있다. → 1년 후 사용자 증가 시 20% 인상.
【답변｜파랑】
연간 구독 플랜으로 설계 가능. 1년 후 20% 인상 규칙은 설정값으로 관리.
- 주변 사람을 추천하면 추천한 사람은 3개월, 추천받은 사람은 1개월의 추가 사용 기간을 받는다.

참고: 무료만 이용할 가능성 높음. PACDORA 유료 전환 <8%.

【답변｜파랑｜가능】
추천인 +3개월 / 피추천 +1개월 쿠폰·기간 연장으로 구현 가능. 대학생 타깃 콘텐츠·블로그 쿠폰과 묶는 것을 권장.
- 무료 10번 중에 자신이 이 사이트로 제작한 박스를 블로그에 올려 홍보하면, 1개월 무료 이용권(쿠폰)을 발행하는 기능을 추가해야 한다.
【답변｜파랑｜가능】
블로그 게시 인증 후 1개월 쿠폰 발급 가능. 블로그 모듈 또는 외부 URL 제출+검수 플로우가 선행되어야 합니다.

4）即将增加（先确认可行性）

- 产品必标信息（KC 标志、认证号等）。
【答复｜蓝｜可行（确认后）】

- 刀版上放设计 → 3D；进一步上传 PDF/.ai 自动生成 3D+展开图。
【答复｜蓝｜调研】
Pacdora：公开能力里没有「上传 PDF/.ai → 自动生成 3D+展开图」这种一键功能。他们常见的是：①选现成盒型，再贴图看 3D；②上传SVG/DXF刀版线，自动折成 3D；③做完后把文件导出成 PDF/AI（导出≠导入自动建模）。

Packative：主流程是选盒型、做设计/AI 出图、再 3D 预览。CAD 侧宣传可导入DXF刀线；同样未见「扔进 PDF/.ai 就自动出展开图+3D」的标准卖点。

BOXCRAFT：「刀版上放设计 → 3D」我们已经有。PDF/.ai 自动生成不是两家标配，建议先维持图片上传+现有 3D；若以后要补，优先考虑 SVG/DXF 刀线上传，而不是硬啃 PDF/.ai。

稳定性：若把任意 PDF/.ai 丢进去自动生成 3D+展开图，很容易出现模型错乱。文件里常混有印刷图、文字、参考线；切线/折线、哪面是盖也往往没有标准标注，机器很难每次都稳定识别。演示或半自动（人工标线）可以做，但很难做到全自动、稳定投产。因此更稳妥的是走模板（或干净的 SVG/DXF 刀线）路径。
