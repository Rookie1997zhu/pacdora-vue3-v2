## 3. 统一设计数据模型（独立方案）

```ts
interface PackagingDesignDocument {
  id: string
  teamId: string
  boxType: string
  params: DielineInput
  knife: DielineOutput // 可缓存，但以 params 为真源
  artwork: {
    layers: ArtworkLayer[] // image/text/shape
    activePanelId?: string
  }
  view3d: {
    foldProgress: number // 0..1，仅视图态
    camera?: object
  }
  revision: number
}
```

### 同步规则

1. **改尺寸**：重算 knife → 更新 2D → 重建 3D 几何 → 重新适配 artwork（按面板局部坐标比例或锚点）
2. **改图案**：更新 artwork → 刷新 2D overlay → 更新对应 face 纹理；**不**改 knife
3. **改 3D 折叠**：只改 `view3d.foldProgress`；**禁止**写回 2D 设计数据

### 坐标

- 世界：刀版 mm，原点左上或文档约定并单点维护
- 面板局部：以面板包围盒左上为 (0,0)
- UV：面板局部归一化到 [0,1]，bleed 外扩按比例

## 4. Three.js 评估

**建议沿用现有 Three.js**（已在依赖与 DielineTool 使用），避免换引擎。对方 3D 为 EngView Collada + 自定义 GLSL（设计空间矩阵投影贴图），PackFlow 不必复刻 EngView，而应对齐「面板局部坐标 ↔ 3D face UV」契约。

增强点：

- 每面板 Mesh + 独立 texture（由 2D artwork + panel mask 烘焙）
- 折叠用 hinge 四元数插值（已有 fold 管线可扩展）
- 阴影/环境光保持克制，服务印前预览而非营销炫光
