## 3. 高置信度推断

1. 营销站 = Next.js on CF Workers；Studio 画布 = Konva + EngView WebGL。
2. **Supabase 账户 ≠ Medusa store customer**；进编辑器/下单依赖后者。
3. 刀版生产链：内部 PDF → poppler → EPS（`papi`）；编辑器侧另有 CDN SVG + EngView 三维。
4. 印前「print-ready」产品行为偏 **异步邮件**，非购物车直链下载。

- 不复制对方 Next/Supabase/EngView；沿用 Vue3 + Django + 现有 Three.js 刀版。
- 规格对齐：AI 适配层、设计文档持久化、面板↔3D UV 契约、生产级导出 Worker。
- 刀版在现有 `integrations/dieline` 上升级，算法独立命名。
