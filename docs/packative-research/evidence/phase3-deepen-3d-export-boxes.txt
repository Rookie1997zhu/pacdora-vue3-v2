## 3D / UV pipeline (verified)
- CAD host alias: NEXT_PUBLIC_ENGVIEW_URL = https://cad.packative.com (EngView Packaging CAD).
- Flow: resize session → get-template-info → resize-template → resource-service Collada (+ TextureResource1..4.png).
- Collada: model/vnd.collada+xml ~1.17MB; library_images → ./TextureResource{1-4}.png
- Texture fetch: 307 redirect to /resource-service/api/v1/resource/hash/{sha256}; sizes observed ~35KB / 77B placeholders.
- Shading: profile_GLSL custom shaders; NEEDSTANYTEXCOORDS; uniforms vertexToDesignMatrix / designToVertexMatrix; varying designPos — design-space projection for artwork mapping (not only classic UV atlas).
- TEXCOORD semantic present (count~15) plus crease/curve attrs crInfo*/curvedInfo*.
- 2D side: Konva; assets area_mask.png + dieline.png + dieline.svg; APIs /v1/editor/dieline (+ /overlay) require X-Tenant-Key.
- Editor UI: fold slider in 3D; Switch to white overlay; WebGL ANGLE NVIDIA.
