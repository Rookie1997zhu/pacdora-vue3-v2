## API (verified)
POST https://studio-api.packative.com/v1/editor/upload
Headers: X-Tenant-Key + X-Tenant-User-Id
Body: multipart FormData (file/image + designId)
Response 200 success=true, data includes:
- id, uuid, filename/originalName, type=image/png, size
- url: studio-cdn.../uploads/{cusId}/{designId}/{uuid}.png
- s3Key/key same path under tenantId
Note: same endpoint also used for canvas layer saves (base-layer.png) in earlier save flow.
