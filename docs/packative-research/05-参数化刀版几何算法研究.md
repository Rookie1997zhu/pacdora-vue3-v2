# 05 — 参数化刀版几何算法研究

## 1. 目标网站观察

### 1.1 已验证

- 英文产品目录可访问多种盒型（见 02）。
- Product Box（crash-lock）支持 Custom L/W/H（mm）；`100×80×50` / KO `120×90×60` 可输入。
- Dieline File 按钮在尺寸有效后可点，出现 `Generating...`。
- **刀版 API（EN 实测）**：`GET papi.packative.com/public/online/model?productCode=productbox-crashlock&length&width&height&format=eps` → EPS；Creator=`poppler pdftops`，`PDF Creator: packative.com`（先 PDF 再转 EPS）。
- **包围盒差分（pt）— crashlock**：`100×80×50`→`1119×626`；`120×90×60`→`1289×696`；`55×55×75`→`722×590`；**计划大尺寸** `200×150×100`→`2083×1065`；`300×200×150`→`2933×1419`。证据：`evidence/dieline-crashlock-*.eps`。
- **多盒型 EPS（已验证 productCode）**：`mailerbox`（100×80×50→984×950；200×150×50→1268×1347；**200×150×100→1835×1772**）、`sleeve`（100×80×50→1117×199；**200×150×100→2081×341**）、`tray`（150×100×40→1095×942；**200×150×100→1917×1764**）、`pillowbox`（80×60×40→440×369；100×80×40→553×454；**200×150×100→950×837**）。均 `poppler pdftops` + `PDF Creator: packative.com`。
- **编辑器 SVG 刀版（已验证）**：`studio-cdn/.../dielines/productbox-crashlock/{L}_{W}_{H}/dieline.svg`；`ev-style="Cutting"|"Creasing"`；同拓扑异尺寸：`100_80_80`≈1406.76×834.163、`55_55_75`≈877.627×664.084、`200_150_100`≈2691.8×1333.06，Cutting=63 / Creasing=14 不变。部分尺寸 CDN 403（未缓存）时 EPS 仍可用。
- **Studio 多盒型同构（已验证）**：editor CDN 路径 `dielines/{productCode}/{L}_{W}_{H}/` — 例 `mailerbox/160_160_70`、`pillowbox/100_65_20`；`main-design-gen` 字段集不变。证据：`phase3-multibox-studio.txt` / `TC-STUDIO-06`。
- **编辑器刀版 API（已验证）**：`GET studio-api.../v1/editor/dieline?product&length&width&height`，头 `X-Tenant-Key` + `X-Tenant-User-Id`。返回 masks（`original_dieline`/`dieline`/`area_mask`/`main_mask`/`total_mask` 及 CDN URL）、`original_svg_url`、画布 `2048×1216`、图 `1407×834`、`evd_uuid`/`db_id`/`papi_code`。元数据：`evidence/studio-api-dieline-100_80_80.meta.json`。
- **CAD**：`NEXT_PUBLIC_ENGVIEW_URL=https://cad.packative.com`（EngView）；resize + Collada resource-service。
- **高置信推断**：展开宽 ≈ `2*(L+W)`（mm→pt）+ 约 `99pt`（≈35mm）边距；高度与 `W+2H` 在小盒接近，大盒偏差更大。
- 编辑器入口（KO）query：`length`/`width`/`height`（+`quantity`/`coating`/`hash`/`designId`/`itemId`）；`hash` 算法未知。
- KO 在 `customer=null` 时刀版下载可出登录墙；EN 同账号可直接 Generating→EPS。

### 1.2 非法尺寸矩阵（已验证 · productbox-crashlock）

`GET papi.../public/online/model` 失败时：`400` + `errorCode: calc-700`（缺参多为 `calc-440`）。

| message | targetValue（观测） | 备注 |
|---------|---------------------|------|
| `length-to-small` / `width-to-small` / `height-to-small` | 25 | 绝对下限提示 |
| `length-to-big` | 400 | L≤400 |
| `width-to-big` | 350 | W≤350 |
| `height-to-big` | 400 | H≤400 |
| `length-2third-width` | null | L 约需 ≥ ⅔ W（例 W=80 时 L≥53） |

EN PDP UI：`Length/Height must be at least 25mm.`；超上限或比例违例 → `Selected dimensions aren't supported. Try adjusting length, width, or height.`  
抽样：mailer `length-to-small`→50；pillow→30。证据：`phase3-illegal-size-*`；用例 `TC-DL-04`。

## 2. 独立几何引擎契约

```ts
type BoxTypeId = string

interface DielineInput {
  boxType: BoxTypeId
  lengthMm: number
  widthMm: number
  heightMm: number
  materialThicknessMm: number
  clearanceMm: number
  foldAllowanceMm: number
  manufacturingToleranceMm: number
}

interface Panel {
  id: string
  name: string
  parent?: string
  side?: 'outside' | 'inside'
  contour: Path2DMm // mm, Y-down or documented
  printArea?: Path2DMm
  safeArea?: Path2DMm
}

interface LineSeg { x1: number; y1: number; x2: number; y2: number; role: 'cut' | 'fold' | 'bleed' | 'safe' }

interface DielineOutput {
  panels: Panel[]
  cutLines: LineSeg[]
  foldLines: LineSeg[]
  glueAreas: Path2DMm[]
  lockingTabs: Path2DMm[]
  bleedAreas: Path2DMm[]
  safeAreas: Path2DMm[]
  boundingBox: { minX: number; minY: number; maxX: number; maxY: number }
  topology: { root: string; faceOrder: string[]; hinges: { a: string; b: string; axis: string }[] }
  validation: { ok: boolean; checks: { id: string; ok: boolean; message: string }[] }
}
```

对齐并扩展现有 [`knifeContract.js`](../../global-toolbox-vue3/src/integrations/dieline/knifeContract.js) 的校验思想（拓扑+数值门禁），但 **算法命名与实现保持独立演进**。

## 3. 生成方法（独立）

1. **模板注册表**：`boxType → template.layout(input) → DielineOutput`（已有 `templates/index.js` 模式）。
2. **参数约束**：每模板声明 `min/max`、关系约束（如 L≥W、插舌 ≤ 宽度一半等）。
3. **重计算**：任何输入变更触发纯函数重算；禁止可变全局缓存污染。
4. **制造检查**：`validateKnife` 风格检查 + 合盖碰撞估计（现有 `foldSim.js`）。
5. **导出**：由统一 layers（trim/crease/bleed）驱动 DXF/SVG/PDF。
