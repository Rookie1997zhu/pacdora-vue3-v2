BOXCRAFT 主要需求事项（一稿）

来源：老板 Word《BOXCRAFT 주요필요사항 1차 261114》。蓝色答复已写在同目录 …_답변.docx。

最重要：让客户轻松理解产品，没有专业知识也能方便设计盒子（功能不能太复杂）。网页工程师单干局限大，需协作推进。

1. BOXCRAFT · 2026年11月第3周

1）内容修改

  • 每个盒子可预先套用设计，立刻看到完成效果。
  • 可选择纸材并反映到预览（牛皮纸自然棕 / 艺术纸光滑印刷感）。
  • 可选纸厚：150g、250g、350g、一瓦楞等。
    1. 先调研韩国常用纸材与厚度。
    2. 像 PACDORA：纸厚变化时内侧与外侧尺寸一并显示。

2）翻译 / SEO

中文站自动翻译 → 韩国搜索引擎难收录。应按国家做内容；按访问国自动显示语言（韩/日等）。

3）博客

  • 介绍盒型与用途（化妆品盒、礼品盒、运输盒等）。
  • 用户分享自己做的盒子，激活社区。

4）即将增加（先确认可行性）

  • 产品必标信息（KC 标志、认证号等）。
  • 刀版上放设计 → 3D 渲染；进一步：上传 PDF / .ai → 自动 3D + 展开图。

5）最难：按数量估价

同款盒对比 100 个与 1,000 个单价（设计师对价格敏感）。

6）外箱连接

包装盒完成后引导做可装 N 个的运输外箱（Outbox）。

7）AI

确认能否用 AI；设计中提前提示风险（如艺术纸 250g 做重物/过高易瘪）。提示 UI 未定。

8）供应链（后续）

对接韩国印刷厂真实下单；协商外箱与包装材一揽子供应。

2. 今后计划

  • MASSCONNECTED：产品尺寸确定后，用本引擎做包装/盒型。
  • 销售：注册免费下载 10 次 → 之后 5,000 韩元+VAT500；年订 3,000+VAT300；一年后可涨 20%。
  • 推荐：推荐人 +3 个月，被推荐 +1 个月（注意免费党；PACDORA 付费转化 <8%）。
  • 目标：方便大学生使用；免费次数内发博客宣传可发 1 个月免费券。

BOXCRAFT 주요필요사항 1차

출처: Word 《BOXCRAFT 주요필요사항 1차 261114》. 파란 답변은 같은 폴더 …_답변.docx에 작성했습니다.

가장 중요: 고객이 전문 지식 없이도 쉽게 박스를 설계할 수 있어야 합니다(너무 복잡한 기능 지양). 웹엔지니어 단독 한계 → 협업으로 진행.

1. BOXCRAFT · 26년 11월 3주

1) 내용 수정

  • 박스별 예상 디자인을 미리 적용해 완성본을 바로 확인.
  • 종이 재질 선택·미리보기 반영(크라프트/아트지 등).
  • 종이 두께(150g, 250g, 350g, 1골지 등) 선택.
    1. 한국 상용 지종·두께 조사.
    2. PACDORA처럼 안쪽·바깥쪽 크기 병기.

2) 번역 / SEO

자동번역 사이트는 한국 검색엔진에 약함. 국가별 콘텐츠 + 접속국 자동 언어 필요.

3) 블로그

  • 박스 종류·활용 소개.
  • 사용자 제작 박스 공유로 커뮤니티 활성화.

4) 곧 추가(가능 여부 확인 후)

  • 필수 표기(KC 마크·인증번호 등).
  • 도면 위 디자인 → 3D; PDF/.ai 업로드 → 자동 3D·전개도.

5) 가장 어려운 기능: 수량별 예상 가격

100개 vs 1,000개 단가 비교 표시.

6) 아웃박스 연결

포장박스 완료 후 배송용 아웃박스 설계로 유도.

7) AI

AI 적용·차별화. 설계 위험 사전 알림(재질·높이 등). UI 미정.

8) 공급망(추후)

한국 인쇄소 연동 실발주. 아웃박스·포장재 일괄 제공 유도.

2. 앞으로의 계획

  • MASSCONNECTED: 제품 치수 확정 후 본 엔진으로 포장.
  • 판매: 가입 후 무료 10회 → 이후 5,000원+VAT; 연간 3,000+VAT; 1년 후 +20% 가능.
  • 추천: 추천인 +3개월 / 피추천 +1개월 (무료만 쓸 위험, PACDORA 전환 <8%).
  • 목표: 대학생 이용. 블로그 홍보 시 1개월 쿠폰.
