# P1.1 首页按需 3D 验收记录

基线：P0 人工回归证据之后。**只做** Hero 静态默认 + 点击后再加载折叠预览；未做 Studio 分屏、Workbench 拖拽分隔、渲染永久归档。

环境：Compose `http://localhost`，前端已重建 `boxcraft-caddy:local`。验证路由：`/home`（`/` 在当前开关下仍进实验室）。

| 用例 | 结果 | 说明 |
|------|------|------|
| 初载无 Three / knifeScene | Passed | 进入 `/home` 后点「3D 보기」前，performance 资源中无 `HomeHero*` / `knifeScene` / `boxModel`；首屏仅静态封面 + CTA |
| 点击加载可交互预览 | Passed | 点击后加载 `HomeHeroFoldPreview-*.js`、`knifeScene-*.js`、`knife-*.js`、`boxModel-*.js`；出现 canvas、合盖滑条与「시점 리셋」 |
| 关闭预览销毁组件 | Passed | 「미리보기 닫기」后回到「3D 보기」；`.hero-fold canvas` 消失 |
| WebGL/几何失败回退 | Not Run | 本轮未强制关 WebGL；失败路径代码会 `emit('failed')` 并显示 `hero3dUnavailable` |
| 中韩文案 | Passed | ko：`3D 보기` / `미리보기 닫기`；zh key：`site.heroView3d` 等已补 |
| 不扣额度 / 不调云渲 | Passed | 预览仅用本地 `createKnifeScene` + workbench 几何，无 export/render job |
| `npm run build` | Passed | 本地与 Docker vue-build 均成功；`HomeHeroFoldPreview` 独立 chunk |
