## 回退要点

1. 保留 `pg_data` / `media_data` 等卷，禁止日常 `down -v`。
2. 无破坏性 schema 时可切回发布前镜像摘要后 `compose up -d`（命令见 bootstrap）。
3. 前端回退：重建旧提交的 caddy 镜像即可。
4. 发布前建议 `docker tag boxcraft-backend:local boxcraft-backend:pre-<sha>`（caddy 同理）以便实机回滚演练。
