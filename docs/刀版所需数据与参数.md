# 做一副刀版需要什么数据 / 参数

面向本仓库 BOXCRAFT 参数化刀版（矩形面板 + 铰链）。**有尺寸 ≠ 有刀版**；缺结构定义时只能当尺寸库用。

相关：打样对照见 [SAMPLE_CHECKLIST.md](./SAMPLE_CHECKLIST.md)；B1 方案见 [BOXCRAFT_B1_参数化结构落地方案.md](./BOXCRAFT_B1_参数化结构落地方案.md)；未映射名单见 `未映射名单/`。

**先分清两种「完成」：**

| 级别 | 含义 | 本仓库状态 |
|---|---|---|
| **软件完整校样** | 有结构模板 + 尺寸 → 能出 2D/3D/导出，自检通过 | 可达到 |
| **生产开模就绪** | 校样 + **实物打样校准** + 工艺签字 | 未达到；`manufacturingReady` 保持 `false` |

下文「做完一副刀版」默认指 **软件完整校样**；开模另见第 10 节。

---

## 1. 一句话分层

| 层级 | 要什么 | 没有会怎样 |
|---|---|---|
| **A. 尺寸输入** | L / W / H / 厚度 / 出血… | UI 填不了数，无法出具体一刀 |
| **B. 结构模板** | 有哪些面、怎么连、怎么折 | 只能借用别的盒型，或无法映射 |
| **C. 工艺与校验** | 补偿、合盖、材质方向 | 能画图但难打样、易告警 |
| **D. 生产就绪** | 实物打样签字 | 本项目保持 `manufacturingReady=false` |

日常「导入尺寸目录」只稳定提供 **A**；自研模板要补齐 **B+C**。

---

## 2. A. 尺寸与工艺输入（用户 / 目录侧）

做**某一规格**的刀版时，至少需要：

| 参数 | 含义 | 单位 | 说明 |
|---|---|---|---|
| **length (L)** | 长度（通常内尺寸） | mm | 与 `sizeMode` 一致 |
| **width (W)** | 宽度 | mm | |
| **height (H)** | 高度 | mm | |
| **thickness (T)** | 纸板厚度 | mm | 影响 panel/outer 补偿 |
| **sizeMode** | `inner` / `outer` | — | 输入是净空还是外廓 |
| **bleed** | 出血 | mm | 外扩示意，非生产出血工艺 |
| **fluteDirection** | 瓦楞方向 | `L` / `W` | 示意标注 |
| **materialId** | 材质示意 | kraft / white / blue | 影响 3D 颜色，非楞型完整定义 |

**可选（部分模板才有）：**

| 参数 | 适用 | 说明 |
|---|---|---|
| **piece** | 天地盖等 | `bottom` / `lid`，两件分看 |
| **lidClearance** | 天地盖天盖 | 套合间隙，默认约 2mm |
| **windowW / windowH** | 开窗类（若模板支持） | 窗孔尺寸 |
| **sides** | 多边形示意 | 墙板片数（当前多为固定 6） |

**仅尺寸目录常有、引擎不用来直接画刀线的字段：**  
名称、来源编号、分类、段数统计、几何索引路径等——用于检索与映射，**不**替代结构模板。

---

## 3. B. 结构模板（自研盒型侧）——「公开展开结构」

新增一种盒型时，需要能回答下面问题（可来自 FEFCO/ECMA、工艺书、实物摊平，**不要**整批拷贝第三方 cuts/folds 当生产资产）：

### 3.1 拓扑（必须）

| 数据 | 模板字段 | 说明 |
|---|---|---|
| 模板 id / 中英文名 / 标准名 | `id` `label` `labelEn` `standard` | 列表与导出文件名 |
| 面列表与顺序 | `faceOrder` | 如 base, back, front, left, right… |
| 根面 | `root` | 3D 折叠树根 |
| 面板矩形布局 | `layout({panel,T,…})` | 每面：`[name, x, y, w, h, parent, side]` |
| 铰链朝向 | 子面的 `side`：top/bottom/left/right | 相对父面哪条边折叠 |
| 默认折角 | `hingeAngles` | 缺省 90°；盖/插舌可略小于 90 |

### 3.2 可矩形化（必须满足引擎）

当前引擎假设：**每个面是轴对齐矩形**，外轮廓由矩形并集得到。

- **适合**：插舌盒、RSC、飞机盒、十字托盘、袖套等  
- **可示意近似**：斜切锁舌、圆挂孔 → 用矩形/短齿代替  
- **不适合单独做模板**：圆柱/塑料曲面、真异形底、多灰板精装件（先标「仅尺寸」）

### 3.3 尺寸范围与补偿（强烈建议）

| 数据 | 字段 | 说明 |
|---|---|---|
| 默认规格 | `defaults` | 选中模板时的初始 L/W/H/T |
| 允许范围 | `limits` | 夹取用 |
| 厚度补偿 | `sizeRule.panelAdd` / `outerAdd` | `panel ≈ inner + panelAdd·T`，`outer ≈ inner + outerAdd·T`；**示意系数，需打样校准** |

### 3.4 内孔 / 撕拉（按需）

| 数据 | 来源 | 说明 |
|---|---|---|
| 矩形孔列表 | `layout` 返回 `holes: [{x,y,w,h}]` | 开窗、挂孔、拉链齿示意 |

### 3.5 合盖示意（建议）

| 数据 | 字段 | 说明 |
|---|---|---|
| 闭合态关键面板对 | `closedCheck.pairs` | 如插舌↔前墙 |
| 闭合 AABB | `closedCheck.buildBoxes` | 非物理干涉，仅告警示意 |

---

## 4. C. 引擎自动生成（你一般不用手填）

有了 A + B 后，`createKnife` 会生成：

- 裁切外轮廓、折线、出血轮廓  
- 面片、铰链、layers（trim / crease / bleed）  
- 尺寸箭头、校验 `validation`、导出 SVG/DXF/PDF/JSON  

这些是**输出**，不是你事先搜集的输入。

---

## 5. 按场景要准备什么

### 场景 1：已有模板，只出某一尺寸

准备：**L、W、H、T**（+ bleed / 材质 / 内或外尺寸）。  
结构不用再找。

### 场景 2：目录里有尺寸，想挂上模板

准备：

1. 名称/编号能对应到哪种结构（或扩 `mapTemplate` 关键词）  
2. 若无对应模板 → 走场景 3，或标「仅尺寸」

### 场景 3：全新盒型自研模板

最少清单：

1. **公开结构参考**（标准图 / 工艺说明 / 实物展开）  
2. **面序 + 父子铰链**（可画成草图）  
3. **L/W/H → 各面宽高的公式**（可先示意）  
4. **厚度补偿系数**（可先抄同类盒，再打样改）  
5. **1～2 个默认尺寸**做检查用例  
6. （可选）合盖配对、窗孔、件别 `piece`

### 场景 4：明确不做结构（塑料、圆柱等）

只保留：**名称 + L/W/H + 厚度** 作尺寸库；不强制 `templateId`。

## 6. 做完一副刀版要做什么（工作流）

按「已有模板出规格」和「新盒型从零做」两条线。目标都是：**能改尺寸重算、能预览合盖、能导出校样文件、自检绿**。

### 6.1 已有模板 → 出某一规格（最短路径）

| 步骤 | 做什么 | 在哪做 |
|---:|---|---|
| 1 | 选盒型（已有的刀版）或从「导入的尺寸目录」选一条已映射条目 | UI |
| 2 | 确认 / 填写 **L、W、H、T**，需要时改内/外尺寸、出血、瓦楞、材质 | 参数区 |
| 3 | 若有件别（如天地盖）切换 **底盖 / 天盖** | `piece` |
| 4 | 看 2D 裁切/折线/出血、3D 折叠与合盖提示 | 主界面 |
| 5 | 导出 SVG / DXF / PDF / Knife JSON（技术校样） | 导出区 |
| 6 | （建议）改一组极限尺寸再看一眼，确认未穿模、外轮廓闭合 | 手工抽检 |

完成标志：`validation.ok`、能导出；界面仍提示 **不可开模**。

### 6.2 目录有尺寸但未挂模板

| 步骤 | 做什么 |
|---:|---|
| 1 | 在未映射名单里标：`可映射` / `需新模板` / `仅尺寸` |
| 2 | **可映射**：扩 `mapTemplate` 或写入 `mapOverrides`（`sourceNum→templateId`）→ `npm run catalog:build` |
| 3 | **需新模板**：走 6.3 |
| 4 | **仅尺寸**：只当尺寸库，借用当前选中模板试看，不强制正确结构 |

### 6.3 新盒型 → 软件完整校样（从零模板）

| 步骤 | 做什么 | 产出 |
|---:|---|---|
| 1 | 确认 **公开展开结构 + 可矩形化**（FEFCO/工艺/实物，不拷贝第三方刀线当生产资产） | 结构草图 |
| 2 | 在 `src/templates/` 新建模板：`faceOrder`、`root`、`defaults`、`limits`、`sizeRule`、`layout`、`closedCheck` | `*.js` |
| 3 | 在 `src/templates/index.js` 注册；在 `src/catalog/index.js` 的 `OWNED_GROUPS` 挂侧栏 | 可选中 |
| 4 | 需要时加 `holes`（开窗/挂孔）、`piece`（两件套分看） | 布局扩展 |
| 5 | 映射：关键词或覆盖表挂上尺寸目录条目 | `mapTemplate` / `mapOverrides` |
| 6 | 跑 `npm run check:templates`、`check:fold`、`npm run check:all` | 自检绿 |
| 7 | UI 抽检：改尺寸、折叠、导出 | 校样可用 |
| 8 | （可选）用 1～2 个参考几何做**量级**对照（面数/展开宽高），不要求折线重合 | 笔记即可 |

完成标志：侧栏可选、改尺寸几何更新、合盖策略可用（或明确示意级）、导出契约字段齐全、`manufacturingReady=false`。

### 6.4 从校样到「能开模」（本仓库尚未默认完成）

| 步骤 | 做什么 | 说明 |
|---:|---|---|
| 1 | 按 [SAMPLE_CHECKLIST.md](./SAMPLE_CHECKLIST.md) 打样 | 缺料/张口/插不进/干涉/出血 |
| 2 | 回写 `sizeRule`、翼宽/插舌公式或输入尺寸 | 改代码后必须再 `check:all` |
| 3 | 复测通过并签字 | 工艺/质量确认 |
| 4 | 再评估是否允许 `manufacturingReady=true` | **未签字前禁止投产** |

没有步骤 1～3，导出文件只能叫**技术校样**，不是完整生产刀版。

### 6.5 完成检查清单（软件校样）

- [ ] 有明确 `templateId`（不是随便借用错结构）  
- [ ] L/W/H/T（及 sizeMode）正确  
- [ ] 2D：裁切闭环、折线落在铰链、出血不穿裁切（示意级）  
- [ ] 3D：能折叠到闭合；合盖检测非 skipped（或已标注未配置）  
- [ ] `npm run check:all` 通过  
- [ ] 已导出至少一种校样格式并打开核对  
- [ ] UI/文档仍标明：非生产开模

## 7. 推荐搜集优先级

| 优先级 | 内容 | 用途 |
|---:|---|---|
| 高 | 内尺寸 L×W×H、纸板厚度 | 立刻出刀 |
| 高 | 盒型结构类型（STE / RSC / 天地盖…） | 选模板或写模板 |
| 中 | 公开展开示意图或实物摊平照片 | 写 `layout` |
| 中 | 内尺寸还是外尺寸、出血要求 | `sizeMode` / bleed |
| 中 | 瓦楞方向、材质 | 标注与预览 |
| 低 | 第三方 JSON 段数、图层名 | 仅作调研索引 |
| 禁止当生产输入 | 第三方完整 cuts/folds 坐标 | 合规与可维护性 |

## 8. 本仓库落点对照

| 你要改/看的 | 路径 |
|---|---|
| 结构模板 | `src/templates/*.js` + `index.js` |
| 生成刀版 | `src/knife.js` → `createKnife` |
| 尺寸目录 | `src/catalog/presets.js`（`npm run catalog:build`） |
| 名称→模板映射 | `mapTemplate` + `src/catalog/mapOverrides.json` |
| 未映射待办 | `未映射名单/` |
| 自检 | `npm run check:all` |
| 打样回写 | [SAMPLE_CHECKLIST.md](./SAMPLE_CHECKLIST.md) |

---

## 9. 验收口诀

- **会填数**：有 L/W/H/T  
- **会对型**：有结构模板（或映射到已有模板）  
- **会出图**：裁切 + 折线 +（可选）出血/孔  
- **会自检**：`check:all` 绿（软件完整校样）  
- **能开模**：仅在实物打样校准并签字之后；在此之前一律视为**技术校样，不可开模**
