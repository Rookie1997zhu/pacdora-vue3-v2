## 回写规则

1. 先改输入参数（L/W/H/T/bleed）复测；仍偏差再改 `knife.js` 比例系数。
2. 改几何后必须跑 `npm run check:all`。
3. **不得**因「软件自检通过」将 `manufacturingReady` 设为 `true`；仅在完成实物打样并签字确认后另行评审。
